# MRR Fantasy Rules

## Squad Selection

- **Budget**: $70 to pick a squad of **9 players**
- **Players**: 6 starting players, 3 bench players
- **Mandatory Selection**: 2 GK players, and 1 of each MID/DEF/FWD for starting lineup
- **Captain**: Earns double points. Cannot keep yourself as captain. If the captain is unable to play, 0 points (no vice-captain substitution)
- **Max 2 Top Players**: You can only add 2 players from the Top Player List
- **Transfer**: 1 player before the deadline per gameweek. Does not pile up each week
- **Deadline**: End of Saturday. Squads, transfers and chips lock at **Saturday midnight ET** and reopen **Sunday 12:00 PM ET**
- **Fantasy Time**: Only first hour of gameplay counts for MRR Fantasy
- **Player Role**: Most players have 2 roles. When selecting, choose a role for that player — points are added based on the assigned position in your squad
- **No Auto Sub**: If any player in the starting lineup doesn't play, it's 0 points. No bench substitution for points

## Scoring System

### Goals

| Position   | Points per Goal |
| ---------- | --------------- |
| Goalkeeper | 10              |
| Defender   | 6               |
| Midfielder | 5               |
| Forward    | 4               |

### Assists

- **5 points** per assist

### GK Saves

- **1 point** for every **5 saves** made (GK only)

### Clean Sheets

| Position   | Points |
| ---------- | ------ |
| Goalkeeper | 2      |
| Defender   | 2      |
| Midfielder | 0      |
| Forward    | 0      |

### Penalty Saves

- **8 points** per penalty save

### Minutes Played

| Condition            | Points |
| -------------------- | ------ |
| Playing 35+ minutes  | 2      |
| Playing 1–34 minutes | 1      |

### Negative Points

| Action                                         | Points |
| ---------------------------------------------- | ------ |
| Regular Foul (dragging, handball)              | -1     |
| Serious Foul (causes serious injury)           | -3     |
| Own goal                                       | -2     |
| Penalty miss                                   | -2     |

## Deadline

- Team selection closes at the **end of Saturday** — the deadline is **Saturday 23:59 ET**
- Squads, transfers and chips are **locked from Sunday 12:00 AM ET until Sunday 12:00 PM ET**
- All times are US Eastern and follow daylight saving, so the deadline is midnight
  on the clock all year round
- Once the deadline passes, every manager's lineup for that gameweek becomes
  visible to the rest of the league
- An admin can reopen selection early if a gameweek is delayed

## Transfers

- **1 free transfer** per gameweek
- Additional transfers cost **-4 points** each
- Transfers must be made **before the Saturday deadline**
- Player prices change based on transfer activity (supply & demand)

## Chips

| Chip           | Effect                                                     |
| -------------- | ---------------------------------------------------------- |
| Triple Captain | Captain scores **triple** points instead of double         |
| Bench Boost    | All bench players score points for that gameweek           |

- Only **one chip** can be played per gameweek
- Chips must be played **before the Saturday deadline**

## League

- Join through invite code
- 4 seasons per league: Summer, Winter, Spring, Fall
- After every season, player points reset to 0 and player prices are updated
